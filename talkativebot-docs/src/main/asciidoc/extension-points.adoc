== Extension Points

Developers customize TalkativeBot by implementing:

[cols="2,3", options="header"]
|===
| Extension | Use case

| `AbstractConversation`
| Orchestration callbacks, conversation-level flow

| `AbstractTopic` + `@Topic`
| Questions, facts, branching, replay

| `ConversationStartResolver`
| Map inbound text/commands to `ConversationStartRequest`

| `ScopedConversationStartResolver`
| Limit a start resolver to selected conversation scopes

| `ConversationRuntimeInitializer`
| Shared WebClients, repositories per conversation type

| `InputChannel` / `OutputChannel`
| WhatsApp, Slack, REST webhooks, custom transports

| `PendingInteractionStore`
| Custom persistence backends

| `OptionSelector`
| Non-standard option matching (NLP, fuzzy match)

| `TopicScanner` / `TopicFactory`
| Non-Spring topic discovery
|===
