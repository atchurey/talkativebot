= Incoming Messages

xref:index.adoc[Documentation Home]

== Incoming message envelope

`IncomingMessage` is the inbound event envelope that client integrations pass into `TalkativeBot.handle(...)`.
The minimal shape is still `ConversationAddress` + `text`, which keeps existing simple integrations working.
Richer clients can also include channel, external identity, referral, metadata, and raw payload references without overloading `ConversationAddress` or placing transport details inside message text.

This distinction matters because `ConversationAddress` is used for routing and pending interaction lookup.
It should identify where a reply belongs.
Its `channel` must identify a TalkativeBot channel that can transport replies.
It should not become the place for client-specific details such as a Facebook page id, webhook message id, campaign referral, display name, phone number, external provider conversation id, provider channel, or raw payload pointer.

[cols="1,3", options="header"]
|===
| Field | Purpose

| `id`
| Unique inbound event id generated by the client integration or by TalkativeBot when the simple constructor is used.

| `address`
| Conversation routing and persistence address. This is what pending interaction lookup uses.

| `text`
| Human-readable message text or command text. Non-text events should still provide a safe text value for resolver/topic compatibility.

| `receivedAt`
| Time the integration received or created the inbound event.

| `eventType`
| Optional event category supplied by the client integration, for example `message`, `postback`, `location`, or `delivery_status`.

| `channel`
| Optional `ChannelInfo` with provider/channel details such as provider name, client channel, integration name, external conversation id, external session id, and external message id.

| `externalIdentity`
| Optional `ExternalIdentity` for the user/customer identity known by the client integration.

| `referral`
| Optional `ReferralContext` for campaign, deep-link, source, or target information that caused the conversation to start or continue.

| `metadata`
| Optional serializable key-value metadata for integration-specific values that do not deserve first-class fields yet.

| `rawPayloadReference`
| Optional pointer to a stored raw payload, log entry, blob key, or trace id. Store a reference instead of stuffing a large webhook body into the message.
|===

`ChannelInfo` describes the source channel from the client integration's point of view:

[cols="1,3", options="header"]
|===
| Field | Meaning

| `provider`
| External provider or platform, for example `facebook`, `whatsapp`, `slack`, or `web`.

| `channel`
| Provider channel or product surface, for example `messenger`, `business_chat`, or `web_checkout`.

| `adapter`
| Name of the application integration component that translated the external event into `IncomingMessage`.

| `conversationId`
| External provider conversation/thread id, if available.

| `sessionId`
| External provider session id, if available.

| `messageId`
| External provider message/event id, if available.
|===

`ExternalIdentity` describes the user as known by the client integration:

[cols="1,3", options="header"]
|===
| Field | Meaning

| `provider`
| Identity provider or platform that supplied the identity.

| `externalUserId`
| Provider-specific user id.

| `displayName`
| Display name supplied by the provider or client integration.

| `phone`
| Phone number when the integration has a trustworthy user phone.

| `email`
| Email address when the integration has a trustworthy user email.
|===

`ReferralContext` carries optional source information:

[cols="1,3", options="header"]
|===
| Field | Meaning

| `type`
| Referral category, for example `ad`, `share`, `deep_link`, or `qr`.

| `sourceId`
| Provider/source identifier.

| `sourceUrl`
| Source URL, if available.

| `targetType`
| Type of thing the referral points to, for example `product`, `order`, or `campaign`.

| `targetId`
| Identifier of the target.

| `campaignId`
| Campaign identifier.

| `metadata`
| Serializable referral-specific details.
|===

[source,java]
----
ConversationAddress address = new ConversationAddress(
        "spring-cloud-stream",
        "6457317820985555",
        "checkout-session-123"
);

ChannelInfo channel = new ChannelInfo(
        "facebook",
        "messenger",
        "srcheckoutbot",
        "page-thread-123",
        "checkout-session-123",
        "mid.abc123"
);

ExternalIdentity externalIdentity = new ExternalIdentity(
        "facebook",
        "6457317820985555",
        "Ada Buyer",
        null,
        null
);

ReferralContext referral = new ReferralContext(
        "deep_link",
        "facebook-ad-42",
        "https://example.test/checkout/product/cheesecake",
        "product",
        "cheesecake",
        "summer-campaign",
        Map.of()
);

IncomingMessage message = new IncomingMessage(
        "event-123",
        address,
        "Cheesecake",
        Instant.now(),
        "message",
        channel,
        externalIdentity,
        referral,
        Map.of("locale", "en-GB"),
        "s3://raw-webhooks/facebook/event-123.json"
);

talkativeBot.handle(message);
----
