# TalkativeBot

TalkativeBot is a Java/Spring Boot library for building stateful conversation flows across channels.

## Features

- Conversation flow abstraction
- Question/answer handling
- Pending interaction persistence
- Spring Boot auto-configuration
- Console channel
- Optional Redis store
- Optional JPA store
- Optional Spring Cloud Stream integration
